# Datasets and references

Complete this file before the submission release.

For every dataset used in the manuscript, record:

- manuscript label / sample name
- project name
- SRA/ENA/other accession
- library/run accession(s)
- source publication
- ancient vs modern classification
- input file type used by the analysis
- exact reference assembly accession/version, where applicable
- exact GFF/GFF3 annotation accession/version, where applicable
- preprocessing steps
- SHA-256 checksum of local analysis input when redistribution is not possible

Do not commit large BAM/CRAM/FASTQ/FASTA files to this repository. Public accessions and exact reference versions should make those inputs retrievable.
