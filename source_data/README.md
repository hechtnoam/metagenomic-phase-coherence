# Numerical source data

This directory contains the numerical source data used for the manuscript
figures and supporting analyses in release v1.0.0.

- `figure_1/`: A2424 59-bp read-position nucleotide frequencies and period-3 statistics.
- `figure_2/`: A2424 59-, 61-, 79-, and 80-bp read-position profiles and period-3 statistics used for the modulo-3 comparison.
- `figure_3/`: original, phase-randomized, and fixed-trim A2424 profiles and period-3 statistics.
- `figure_4/`: nucleotide-frequency profiles and DFT spectra for the original and phase-randomized data.
- `figure_5/`: selected read length and mean period-3 R2 for each library in the cross-library analysis.
- `figure_6/`: per-base, per-replicate fragmentation-simulation results.
- `figure_7/`: empirical six-state EM nucleotide probabilities and synthetic known-state validation summaries.
- `coding_frame_analysis/`: matched coding-frame-normalized and unnormalized nucleotide profiles and period-3 statistics.
- `phase_redistribution_replicates/`: period-3 statistics for the independent phase-randomization replicates.

Large raw sequencing files, reference genomes, simulated reads, and generated
intermediate analysis directories are not included.
