# AncientMetagenomeDir metadata

`ancientmetagenome-environmental_libraries.tsv` is the exact
AncientMetagenomeDir environmental-library metadata table used to annotate
the ancient-DNA libraries in the cross-library analysis and Supplementary
Table S1.

The table contains project, sample, sequencing-library, archive-accession,
download-link, checksum, and library-preparation metadata. The historical
upstream Git release/commit could not be reconstructed reliably; therefore,
the exact TSV used for the manuscript is archived here. Its SHA-256 checksum
is recorded with the Supplementary Table S1 provenance information.

Raw sequencing reads are not redistributed in this repository.
